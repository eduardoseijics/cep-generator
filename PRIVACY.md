# Política de Privacidade — Gerador Brasileiro

**Última atualização: 26 de agosto de 2026**

O Gerador Brasileiro é uma extensão do Chrome que cria dados fictícios para testes e desenvolvimento, como CEP, CPF, CNPJ e números de cartões.

## Dados armazenados

A extensão pode armazenar localmente no navegador:

- preferência de tema;
- aba e tipo de gerador selecionados;
- preferências de máscara;
- histórico de CEPs e CEPs personalizados;
- últimos documentos e cartões gerados.

Esses dados são usados exclusivamente para manter as preferências e o estado da extensão entre as sessões. A extensão não envia esses dados para servidores externos.

## Coleta e compartilhamento

A extensão não coleta, vende, compartilha ou utiliza dados pessoais para publicidade. Não usa cookies, rastreamento, analytics ou conteúdo de páginas visitadas.

## Permissão utilizada

A permissão `storage` é usada somente para salvar localmente as preferências, o histórico e os dados gerados necessários ao funcionamento da extensão.

## Exclusão dos dados

Os dados podem ser removidos pelo usuário limpando os dados de armazenamento da extensão nas configurações do Chrome ou removendo a extensão.
